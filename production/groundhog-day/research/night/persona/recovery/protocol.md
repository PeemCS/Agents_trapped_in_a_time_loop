# Repairing the actor's answer channel

The original native thinking-mode shoot is frozen. On its 34 held-out A/B menus the first adapter produced no executable decision. The common observed form was an answer inside an unterminated thinking block followed by EOS. The engine never promotes that text into a visible action.

## Serving rescue

Use the official Qwen non-thinking chat template, which closes an empty thinking block in the input. Repeat all 34 original menu opportunities with neutral base and original adapter under matching prompts, batch positions, seed schedule, token cap and sampler. Raw text and completion status stay in separate rescue files. These measurements describe an explicitly different serving mode. They cannot replace the original thinking-mode outcomes.

## Native thinking repair

Train a second rank-eight LoRA directly from the same frozen Qwen base with the identical 104 teaching cards, choices, speech, initialization seed, optimizer, step count and schedule. Change the teacher sequence to match the native thinking-on inference format. Supervise the opening tag, a brief author-written stage observation, the closing tag, then the original decision/line and EOS. Each of the 12 settings gets one observation, reused across actors and answer orders. These observations describe which task must be decided before the line. They contain no option label, name preference or chosen outcome. They are authored training examples. Preserve every rendered target and adapter separately.

Run the repaired adapter with native thinking enabled on the same 34 menus and two stand-alone film scenes. Compare against the frozen original base and adapter. Use separate, previously unsampled scarce-seat settings to test whether it follows the former helper under a name swap when that costs Phil his own connection. Those scenes offer a third action unavailable in the teaching cards. Add two binary-format locations that use new subject matter, the restored actor and a matched base. A same-distribution success can coexist with a three-action transfer failure. Native output must close its own thinking block before a subsequent decision may execute.

The repaired native shoot and serving rescue are prospective follow-ups to a failure observed on the original test. Results on those 34 menus are therefore development-set comparisons. The scarce-seat and fresh binary locations are new tests. The project uses one existing H100 with the same 10.75 GiB allocator cap.
